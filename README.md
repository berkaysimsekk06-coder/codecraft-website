# CodeCraft - Öğrenci Yazılım ve Teknoloji Topluluğu

## Projenin Amacı
CodeCraft, üniversite öğrencilerini yazılım geliştirme, yapay zeka araçları ve modern web teknolojileri konusunda bir araya getiren, pratik projeler yapmalarını sağlayan bir topluluk platformudur.

## Hedef Kullanıcı
Yazılım öğrenmek isteyen, teknoloji projelerine ilgi duyan üniversite öğrencileri ve junior geliştiriciler.
